# Правила работы с проектом

- Новые докстринги, комментарии, документация, сообщения коммитов, заголовки и
  описания pull request пишутся на русском. Технические идентификаторы и названия
  библиотек сохраняются в исходном виде.
- Рабочая ветка — `develop`. Изменения готовятся в отдельных ветках от неё.
  Ветку `main` обновлять только по отдельному запросу пользователя.
- Код приложения находится в `src/promptexplorer`, интерфейс — в `ui`,
  тесты — в `tests`, инструкции — в `docs`, вспомогательные команды — в `scripts`.
- Слой хранения не должен зависеть от Qt. Импорт и миграции обязаны быть атомарными.
- Перед миграцией существующей базы создаётся резервная копия. Не удалять и не
  исправлять неоднозначные пользовательские данные молча.
- Перед отправкой изменений запускать `python -m pytest`, `ruff check .`,
  `ruff format --check .` и сборку пакета. Изменения упаковки проверять сборкой приложения.
- Тесты используют только временные базы и изолированные настройки. Не открывать
  пользовательскую базу для проверки новой версии.
- Новые изменения поведения сопровождаются записью в `CHANGELOG.md`.
