# Данные, обновление и восстановление

По умолчанию используются прежние папки, чтобы программа нашла существующую библиотеку:

- Windows: `%APPDATA%/PromptExplorer`.
- Linux: `~/.promptexplorer`.

База — `promptexplorer.sqlite3`. Точный путь отображается при выборе профиля.
Для отдельного запуска можно задать `PROMPTEXPLORER_DATA_DIR`. В этом режиме и база,
и настройки, и журнал хранятся в выбранной папке.

Перед обновлением схемы существующей базы создаётся файл вида
`promptexplorer.before-vВЕРСИЯ-ДАТА-ИДЕНТИФИКАТОР.sqlite3` рядом с основной базой.
Если копию создать нельзя, обновление не выполняется. Если преобразование завершается
ошибкой, изменения схемы и данных откатываются.

Кнопка «Резервная копия» сохраняет все профили. Существующий файл не перезаписывается:
для очередной копии нужно выбрать новое имя. Экспорт в txt сохраняет только текущую
выборку с учётом категории и поиска; он предназначен для чтения, а не для восстановления.

Чтобы восстановить всю библиотеку:

1. Закройте все экземпляры PromptExplorer.
2. Сохраните текущий файл базы отдельно.
3. Скопируйте резервный файл в папку данных под именем `promptexplorer.sqlite3`.
4. Запустите приложение. Копия старой версии при необходимости будет обновлена автоматически.

Чтобы вернуть отдельный профиль, используйте «Импорт профиля» и выберите резервную базу.
Импорт создаёт новый профиль и не заменяет существующий.

Превью хранятся внутри базы и входят в резервные копии и импорт профиля.
Новая схема не предназначена для открытия старой версией приложения. Для отката
к прежней версии используйте именно резервную копию, сделанную до миграции.
Копии автоматически не удаляются. Журнал `promptexplorer.log` хранит ошибки с ротацией
до трёх архивных файлов по 1 МБ.
